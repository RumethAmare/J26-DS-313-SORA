# Romanized Tamil lexicon for C1 Task 5 (OTHER = Tamil) detection.
#
# Common Tamil function words, pronouns, numerals and high-frequency verbs, in
# Latin transliteration. Used two ways by scripts/otherlang_flag.py:
#   1. as a gazetteer for high-precision exact hits
#   2. as training data for the character n-gram Tamil model
#
# Everything here is normalised through script_normalize.normalize_scripted()
# before use, so spelling variants (illai / illae / ilai) collapse together and
# match Sinhala-script Tamil after romanisation (ඉල්ලයි -> ilayi).
#
# EXPANDING THIS FILE IS THE HIGHEST-LEVERAGE IMPROVEMENT for Task 5 -- the
# detector is limited by lexicon coverage, not by model capacity. A real
# romanized-Tamil word list (or a transliterated Tamil frequency list) would
# help far more than a larger model.
#
# CAVEAT: this list was hand-written, and it necessarily contains the handful of
# Tamil words that appear in the corpus (sari, periya, illai, puriyum) because
# those are among the most common words in the language. Gazetteer results are
# therefore reported as "deployment-realistic but not held-out"; the n-gram
# detector is evaluated leave-one-out so it has a clean number.
